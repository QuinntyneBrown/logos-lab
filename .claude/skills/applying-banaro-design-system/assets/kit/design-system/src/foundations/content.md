## Principles

The voice matches the visuals: **calm, warm and unhurried**. Copy is specific, uses plain words and treats
people as capable adults.

- **Sentence case everywhere.** Headings, buttons, tabs and menu items: "Invite a teammate", not "Invite A
  Teammate".
- **Verbs on actions.** Name the object: *Save changes*, *Send invitation*, *Delete project*. Never *OK*,
  *Submit* or *Click here*.
- **Specific over clever.** "3 tasks due this week" beats "You're on fire!". No exclamation marks, no
  urgency theatre, no guilt.
- **Numbers as numerals:** 3 tasks, 1,284 people, 40 km. Dates read *Sat 17 Oct*; times read *10:00 am*,
  with the timezone when people are in different places.

## Specimens

| Moment | Formula | Example |
|---|---|---|
| Error | What happened, what is safe, one fix | Note not saved. Your text is still here. Try again. |
| Empty | What is absent, one way forward | No notes yet. Start one for this week's plan. |
| Confirmation | What changed, with an undo if possible | Project archived. Undo |
| Destructive | Name the object and the consequence | Delete Northwind? Its 24 tasks and notes are removed for everyone. |
| Loading | What is coming | Loading your projects |

## Usage

- Keep the product's nouns stable. Use the same names in navigation, headings and buttons.
- Write help text that answers "why are you asking?" and keep it under two lines.
- Placeholder text is an example, never a label.
- Names and user content can be long. Design for 40 characters and let them wrap.
