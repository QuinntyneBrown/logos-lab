RSVP panel

A sample domain panel for reserving a place at a gathering, kept as a reference. It says whether there is room, shows how full it is and holds the one action that fits.

Overview

This is a sample component. It comes from the original Banaro domain (reserving a spot at a gathering) and ships as a worked example of a booking side panel, not as part of every system. An app should either prune it (audit_usage.py --prune removes it when no mock uses .rsvp) or adapt it for its own capacity-limited action (enrolling in a course, booking a slot) by copying the block and renaming the classes. It sits in the aside of the event's page next to the event header. For a generic side box use an aside card.

Kit component; mocks have not been written yet.

Anatomy

  1. Panela surface with a hairline border (.rsvp); sage-washed once you are going (--going), linen once it is closed (--closed).
  2. Titlewhat the panel is for right now (__title): Reserve a spot, You're going, Field Day is full.
  3. Status or textone line of terms or status (__text, or an inline message).
  4. Metera progress bar with the count beneath (__meter), so people see how full it is.
  5. Actionsone full-width primary action and at most one quiet or text action (__actions).

Sizes

One size. The panel takes the width of the page's aside column (--layout-aside-width) or the full width on phones.

States

Focus rings the panel's first action. Loading keeps the button's label and width and adds a spinner while the reservation is saved. Error keeps the panel as it was, adds a danger message that says what to do, and turns the action into Try again.

Responsive behaviour

At 360px the panel is full width and sits directly under the event header, before the description, so the action is on the first screen. From 768px it keeps that place. At 1024px and up it moves into the aside column beside the description and stays in view while the page scrolls.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: an <aside> labelled by its title. The meter is a role="progressbar" with aria-valuenow, aria-valuemin, aria-valuemax and an aria-label; the count beneath repeats it in words.

KeyEffect
Tab / Shift+TabMoves through the panel's actions.
Enter, SpaceActivates the focused action.

Focus: after reserving, focus moves to the new title ("You're going") so the change is announced; on error it stays on the action.

Labelling: the title changes with the state so the panel's name always says where you stand. A busy button sets aria-busy="true" and keeps its label. Errors use role="alert". Status is text with an icon, never colour alone.

Motion: the meter fills without animating under reduced motion; the spinner stops.

Touch: actions are full-width 44px pills.

Content

Titles say where the person stands: Reserve a spot, You're going, Field Day is full, This gathering has ended. Counts read 18 going · 12 spots left. Terms are one sentence (Free. You can cancel up to Friday evening.). Errors say what did not happen and what is still true: We couldn't cancel your spot. You're still going.

Do and don’t

Tokens

The panel reads the surface and hairline roles, --color-accent-subtle and --color-accent for the going state, --color-bg-subtle when closed, the progress track and fill, and the status roles.

Code

Use aside.rsvp with __title, a status line or __text, an optional __meter and __actions. Add rsvp--going or rsvp--closed for those states and set --ll-progress-value on the bar. When adapting, rename the rsvp classes and the @component rsvp-panel block together.

<aside class="rsvp" aria-labelledby="s2236-rsvp-open"><h3 class="rsvp__title" id="s2236-rsvp-open">Reserve a spot</h3><p class="rsvp__text">Free. You can cancel up to Friday evening.</p><div class="rsvp__meter"><div class="progress" role="progressbar" aria-label="Spots taken" aria-valuenow="18" aria-valuemin="0" aria-valuemax="30" style="--ll-progress-value: 60%"><div class="progress__bar"></div></div><p>18 going · 12 spots left</p></div><div class="rsvp__actions"><button class="btn btn--primary btn--block" type="button">Reserve a spot</button></div></aside>
