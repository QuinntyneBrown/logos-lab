Divider

A single hairline that separates groups of content when spacing alone is not enough.

Overview

Reach for space first: most groups separate cleanly with --space-8 and a heading. Use a divider when two groups sit close together and still need to read as separate — the sections of a settings form, two sets of toolbar actions, or the "or" between two ways to sign in. Don't wrap content in boxes to separate it; a card is for an object, not a gap.

Not used in the mocks yet.

Anatomy

  1. Rulea 1px hairline in --color-border-default, never darker.
  2. Labeloptional overline text centred between two rules (.divider--label).
  3. Spacing--space-6 above and below a horizontal or labelled divider; none on a vertical one.

Responsive behaviour

Horizontal and labelled dividers span their container at every width. A vertical divider in a toolbar that wraps at 360px can end up dangling at the start or end of a line; when a toolbar wraps below 768px, drop the vertical divider and let the cluster gap separate the groups.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: a native <hr> is a separator. Use it when the break is meaningful. A labelled divider is a plain paragraph of text, so its word ("or") is read in place.

Labelling: a vertical <hr> inside a toolbar takes aria-orientation="vertical". Decorative rules that only tidy a layout can be borders on the surrounding element instead of separators.

Motion: none.

Touch: dividers are not targets; keep at least --space-2 between the controls on either side of a vertical divider.

Content

The labelled divider holds one lowercase word: or, and, then. Never a sentence, never a heading in disguise; if the group needs a name, give it a real heading.

Tokens

Dividers read --color-border-default for the rule, --color-fg-subtle and the overline style for the label, and --space-6 for their margins.

Code

Use <hr class="divider"> for horizontal breaks, add divider--vertical inside a flex row, and use <p class="divider--label"> for a labelled break.
