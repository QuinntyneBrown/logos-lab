Brand

The product's mark and lowercase wordmark. A quiet line drawing in the accent, with one warm sun dot.

Overview

The brand sits first in the top bar and links home. Use the wordmark with the mark wherever there is room, the mark alone where there isn't, and the unlinked lockup on screens that should not offer a way out, such as sign-in and e-mail. The brand is not a heading and not a button: page titles belong in the page header.

The Logos Lab mark is an open book whose gutter rises into a small cross, the Word above the page, with the sun dot rising beside it. It is drawn in the house style: a 32×32 viewBox, fill="none" stroke="currentColor", a 1.6 stroke with round caps, and one small filled circle with class="brand__sun" — the warm sun dot that every Banaro-style product keeps.

Used in 9 mock states.

Anatomy

  1. Linkthe whole lockup is one <a> with aria-label="Logos Lab home".
  2. Marka 32px inline SVG, line-drawn in --color-accent, aria-hidden="true".
  3. Sun dotcircle.brand__sun, filled with the warm --color-warning-icon; the signature motif.
  4. Wordmarkthe product name, logos lab, lowercase, semibold, slightly tightened.

Sizes

one size. The mark is 32px and the wordmark uses --font-size-lg; the lockup has a 44px minimum height, so the link is a comfortable target. Don't scale the brand up for heroes; let the hero title carry the page.

States

Hover deepens the mark to --color-accent-hover and lifts the sun dot 2px, a small sunrise; the wordmark stays in the default text role. Keyboard focus draws the shared sage ring around the whole 44px lockup. The static lockup has no states.

Responsive behaviour

The lockup never wraps. Below 30rem in a crowded bar (search, three actions), switch to the mark only; at 768px and 1024px and up the wordmark always shows. The brand keeps its 44px target at every width.

Theming

The mark reads --color-accent, so it turns light sage in dark mode; the sun dot reads --color-warning-icon and stays warm in both themes. The wordmark uses --color-fg-default. Never recolour the lockup per page.

Accessibility

Role: a native link home (<a href>), named by aria-label="Logos Lab home". The SVG is aria-hidden="true". The static lockup is role="img" named Logos Lab.

KeyEffect
Tab / Shift+TabMoves focus to and from the brand; it is the first stop after the skip link.
EnterGoes to the home page.

Focus: the 2px --color-focus-ring, offset 3px, wraps the mark and the wordmark together.

Labelling: the accessible name says where the link goes: "Logos Lab home". Keep the visible wordmark inside the link so the name and the visible text agree. On the home page itself, keep the link and add aria-current="page".

Motion: on hover the mark's colour changes over --duration-base (420ms) and the sun dot rises 2px over --duration-slow (640ms); reduced motion removes both transitions and the dot simply moves.

Touch: the lockup is at least 44px tall in the top bar. The mark-only link keeps the same 44px target.

Content

Write the product name exactly as the wordmark does: logos lab in the lockup, Logos Lab in sentences and in the accessible name. Never add a tagline, a version number or "Beta" inside the lockup; put status in a badge beside it.

Code

Paste the lockup as inline SVG (never an <img>) so the mark follows the theme through currentColor. To replace the mark, change only the <path>; keep the viewBox, the stroke attributes and circle.brand__sun.
