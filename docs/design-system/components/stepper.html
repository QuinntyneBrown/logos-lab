Stepper

Show where someone is in a short, ordered flow. A row of quiet bars that fill with sage as each step is done.

Standard componentContrast verified

Overview

Use a stepper above a flow of three to five steps that must happen in order: setting up a workspace, creating a gathering, importing notes. It answers two questions at a glance: how far along am I, and how much is left. It is not navigation; people move with the flow's Back and Continue buttons (see form layout). For parallel views, use tabs; for a single long task, a progress bar.

Kit component; mocks have not been written yet.

Anatomy

  1. Listol.stepper named for the flow, so the step count is announced.
  2. Bareach step's 4px rounded bar: the default border role ahead, sage once done or current, the danger role when the step has errors.
  3. Position"Step 2 of 3" in the caption style.
  4. Namewhat the step is about, in a few words.
  5. Current steparia-current="step"; done steps add .is-done and a visually hidden "done".

Stepper · with errors

Sizes

one size. Bars are --space-1 (4px) tall and share the row equally; text uses the caption style with --space-2 between steps.

States

Steps ahead are the default border bar with subtle text. Done steps and the current step fill the bar with sage and take the default text role; only the current step has aria-current="step". Invalid turns a step's bar and text to the danger roles and says how many answers to check. Complete fills every bar on the final review or confirmation screen.

Responsive behaviour

  • 360px: the row keeps every bar; names wrap within their column and break long words. With five steps, drop the names and keep "Step 4 of 5" with the current step's name in the page title.
  • 768px: the full row with names.
  • 1024px and up: the row above a narrow form, or .stepper--vertical in a side column beside it.

Theming

Every colour reads a semantic role. In dark mode filled bars turn light sage, empty bars use the dark default border and the invalid bar uses the dark danger fill.

Accessibility

Role: an ordered list (<ol>) with an aria-label naming the flow; the current step has aria-current="step". Done steps add a visually hidden ", done" so the state is not carried by colour alone. Links to done steps are ordinary links.

KeyEffect
Tab / Shift+TabReaches only the links to done steps; plain steps are not focusable.
EnterFollows a link back to a done step.

Focus: links show the shared 2px --color-focus-ring. On each new step, move focus to the step's heading so the new position is announced.

Labelling: "Step 2 of 3" is real text, so the position is read even where the list count is not. An invalid step says how many answers to check in words.

Motion: bars fill without animation; nothing to reduce.

Touch: the stepper is not a control; only links to done steps are targets, and their rows are at least 24px tall.

Content

Name each step with a short noun phrase in sentence case: Your profile, Date and place, Review. Always write the position as Step 2 of 3. Keep names to three words in a horizontal stepper. An invalid step says what to do: 2 answers to check, never "Error".

Do and don’t

Tokens

Steps read the default border, accent and danger fills for the bars, the subtle, default and danger text roles, --text-caption and --space-1 for bar height.

Code

Mark done steps with .is-done, the current one with aria-current="step", and a step with errors with .is-invalid. Add .stepper--vertical for a column.

<ol class="stepper" aria-label="Set up your workspace"><li class="stepper__step is-done"><span>Step 1 of 3<span class="vh">, done</span></span><span>Your profile</span></li><li class="stepper__step" aria-current="step"><span>Step 2 of 3</span><span>Invite your team</span></li><li class="stepper__step"><span>Step 3 of 3</span><span>First project</span></li></ol>
