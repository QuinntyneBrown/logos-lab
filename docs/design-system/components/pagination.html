Pagination

Move through a long list a page at a time. The signature is calm: one Show more button, a thin sage meter and a plain count.

Overview

Use pagination below any list that is too long to show at once: search results, notes, people. The default is load more: one quiet button that appends the next page, a meter that shows how far through the list someone is, and a count. It keeps people's place and works well with filters. Use numbered pages when people need to return to a known position or share a link to page 3, and previous and next for small, fixed-size views such as a table in a card. Don't paginate lists under 30 items; show them all.

Kit component; mocks have not been written yet.

Anatomy

  1. Container.pager, centred below the list with generous space above it.
  2. Actiona quiet, large Show more button; or .pager__pages, a row of previous, page and next controls.
  3. Meter.pager__meter, a 2px track with a sage fill set by --ll-pager-progress; decorative.
  4. Count.pager__text, tabular figures in the subtle text role; it is the meter's text equivalent.

Variants

Load more

The default. The button appends the next page below the last item and moves focus to the first new one.

Sizes

one size per variant. Show more uses the large button (52px) so it reads as the end of the list; page controls use the default 44px size. The meter is --size-pager-meter (16rem) wide and --border-width-thick tall.

States

The controls follow button: hover adds the linen wash, focus draws the sage ring. While the next page loads, the button keeps its label, adds a spinner and sets aria-busy="true"; the list keeps its place. When everything is shown (complete), the button goes away, the meter fills and the count says so; in a previous and next pager the control at the end is disabled. The current page in numbered pages is the sage pill with aria-current="page".

Responsive behaviour

  • 360px: load more is unchanged; numbered pages collapse to Previous, "Page 3 of 13" and Next so the row never wraps; the meter shrinks to the container.
  • 768px: numbered pages show the first, last and one page either side of the current one.
  • 1024px and up: two pages either side of the current one. The pager stays centred under the list at every width.

Theming

Every colour reads a semantic role. In dark mode the meter's fill and the current page turn light sage, the track is the dark default border and the count stays in the subtle text role. --ll-pager-progress is the only knob.

Accessibility

Role: load more is a native <button>; numbered pages are links inside <nav aria-label="… pages">, with aria-current="page" on the current one; previous and next in place are buttons. The meter is role="presentation": the count says the same thing in words.

KeyEffect
Tab / Shift+TabMoves between the pager's controls.
Enter, SpaceActivates Show more, Previous or Next. Page links activate with Enter.

Focus: after Show more, move focus to the first new item so keyboard users continue where the new content starts. After paging in place, keep focus on the control that was pressed. Never send focus to the top of the page.

Labelling: page links are named "Page 3", not "3". The count is aria-live="polite", so the new total is announced after loading. On the last page, disable Next rather than removing it, so the row doesn't shift under the pointer.

Motion: new items may settle in with the shared entrance; the meter's fill changes without animation. Reduced motion removes the entrance.

Touch: every control is at least 44px. Show more spans the comfortable large size so it is easy to hit with a thumb.

Content

Say what loads and how many: Show 12 more notes, not "Load more" or "More". The count uses figures and the item's name: 12 of 148 notes · page 1 of 13, Showing 25–36 of 148 notes. At the end, say All 148 notes shown; never "No more results".

Code

Set --ll-pager-progress on .pager__meter to the share already shown (12 / 148 is 8%). Use nav.pager with a name when it holds page links; a plain div.pager is enough around a single Show more button.

<div class="pager"><button type="button" class="btn btn--quiet btn--lg">Show 12 more notes</button><div class="pager__meter" role="presentation" style="--ll-pager-progress: 8%"><span></span></div><p class="pager__text" aria-live="polite">12 of 148 notes · page 1 of 13</p></div>
