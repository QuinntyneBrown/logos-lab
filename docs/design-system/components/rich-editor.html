Rich editor

The studio's article body editor: a formatting toolbar, a writing surface that shows the text as readers will see it, and a status bar with the word count and save state.

Overview

Experts and editors write article bodies, lesson text and course descriptions in the rich editor. The surface uses the same prose styles readers see, so there is no separate preview for the text. The toolbar covers only what Logos Lab publishes: bold, italic, two heading levels, quotes, links, Scripture references and images. For a plain multi-line answer use a textarea; for comments use the comment composer.

Used in 1 mock state.

Anatomy

  1. Editordiv.editor, a birch box with a strong hairline; focus inside it rings the whole editor.
  2. Toolbar__toolbar, a role="toolbar" button group (btn-group--toolbar) of ghost icon buttons; toggles carry aria-pressed. __sep divides groups.
  3. Surface__surface, the editable area holding .prose; at least --space-40 tall.
  4. Status__status, the word count and reading time on the left, the save state on the right.
  5. Flag__flag, a dashed danger outline around content that blocks publishing, such as an image with no alt text.

Sizes

the editor fills the form column; the surface grows with its content from --space-40.

States

Focus inside the surface or toolbar rings the whole editor. Toolbar toggles show their pressed state with the sage wash. Invalid turns the border danger, flags the content that blocks publishing with a dashed outline and explains it below the editor; publishing stays blocked until it is fixed.

Responsive behaviour

The toolbar wraps onto a second row at 360px; the separators keep the groups readable. The surface padding stays 24px. The status bar wraps the save state under the word count on narrow screens.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: the surface is a multi-line textbox labelled by the field label. The toolbar is a toolbar with roving tabindex: one Tab stop, arrows inside.

KeyEffect
TabMoves between the toolbar and the surface.
Left / Right arrow in the toolbarMoves between buttons.
Ctrl + B / Ctrl + IBold / italic.
Ctrl + KOpens the Link dialog.
Ctrl + Alt + 2 / 3Heading 2 / Heading 3.

Focus: after a toolbar dialog (Link, Scripture reference, Image) closes, focus returns to the surface at the caret.

Labelling: every toolbar button has a name; toggles report aria-pressed. The save state is a polite status. The invalid message is linked with aria-describedby.

Motion: none beyond the spinner, which stops under reduced motion.

Touch: toolbar buttons are 44px; on a phone the toolbar stays above the on-screen keyboard.
