Diff

What changed between two versions of a piece of content, field by field: removed lines in red, added lines in green, inline insertions and deletions, and two versions side by side when an edit conflicts.

Overview

The studio shows a diff wherever someone needs to see what changed: in version history, when an editor reviews a resubmission, and when two people saved the same item at once. Each field is its own block so a long article body does not hide a changed title. Use diff-split only to choose between two versions. For review comments on a passage use the annotation; for an audit log of who did what use the timeline.

Not used in the mocks yet.

Anatomy

  1. Diffdiv.diff, a birch block with a hairline, one per field.
  2. Field__field, the field's name on a sunken strip.
  3. Row__row, a sign column and the text; __row--removed on the red wash, __row--added on the green.
  4. Sign__sign, a minus or plus in code type, hidden from screen readers.
  5. Text__text, the line, with visually hidden "Removed:" or "Added:" before it.
  6. Inline changedel.diff__del and ins.diff__ins inside an unchanged row, for small edits within a sentence.
  7. Splitdiff-split, two panes (__pane) each with a head (__head) naming the version and a Keep button.

Responsive behaviour

Rows wrap long text and never scroll sideways. diff-split stacks its panes below 768px (yours first) and sits side by side from 768px.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: each diff is a group named after its field. Removed and added lines carry visually hidden "Removed:" and "Added:"; del and ins are announced by screen readers that support them, and the colour is never the only cue (the sign and the underline on ins remain).

KeyEffect
TabMoves to each pane's Keep button in a split.
Enter or SpaceChooses that version.

Focus: after choosing a version, focus moves to the confirmation button below the split.

Labelling: split panes are named by their head: who saved them and when.

Motion: none.

Touch: Keep buttons are small pills with a 44px target.

Content

Name fields as the editor does: Title, Summary, Body, Cover image. Name versions by person and time: Saved by Naomi Ellis at 10:21 am, Your version, not saved. Keep buttons name whose version: Keep yours, Keep Naomi’s.

Code

Link tokens/tokens.css and assets/components.css, then use this markup. The data-state attribute only forces a state for review; production code uses real interaction and native attributes.

<div class="diff" role="group" aria-label="Changes to Title"><p class="diff__field">Title</p><div class="diff__row diff__row--removed"><span class="diff__sign" aria-hidden="true">−</span><span class="diff__text"><span class="vh">Removed: </span>Augustine and the Language Machine</span></div><div class="diff__row diff__row--added"><span class="diff__sign" aria-hidden="true">+</span><span class="diff__text"><span class="vh">Added: </span>What Augustine Might Say About Large Language Models</span></div></div>
