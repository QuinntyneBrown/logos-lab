Person list

Introduce people as calm rows of small square portraits, a name that links to them and one line of context.

Standard componentContrast verified

Overview

Use a person list to show a handful of people — a team, the people going to Field Day, who worked on a note — when the name and one line of context are enough to decide whom to open. Rows are separated by hairlines rather than boxed, so a page of people stays light. When each person needs facts, actions and a summary, use a card grid; for a single person's page, use a profile header.

Kit component; mocks have not been written yet.

Anatomy

  1. Portrait.person__photo, a 64px square with --radius-md; decorative (alt="") because the name sits beside it. People without a photo get initials on a tile.
  2. Name.person__name, an h3 in the h4 role whose link opens the person.
  3. Meta.person__meta, one muted line: role · team or place.
  4. Open line.person__open, optional: a status pill or one small link.
  5. Row.person, a two-column grid with a hairline under it; the list draws the top hairline.

Sizes

Two densities by modifier: the default row (64px portrait, 24px vertical padding) for a page of people, and people--stacked (48px portrait, 16px padding, one column) for asides and side panels.

States

Rows are passive; the name link carries the states. Hover underlines the name and eases the portrait to 103%; keyboard focus draws the sage ring around the name. A person's own status lives in the open line, never in the row's colour.

Responsive behaviour

  • 360px: one column; each row keeps the portrait beside the text. Long names and meta lines wrap.
  • 768px: two columns with the layout gutter between them; hairlines run under each row.
  • 1024px and up: three columns. people--stacked stays one column at every width.

Theming

Rows sit directly on the canvas and read --color-border-default for their hairlines. Pills read --color-accent-subtle with --color-fg-accent, or the neutral subtle surface. The portrait placeholder reads --color-bg-subtle while the image loads.

Accessibility

Role: a <ul> of people; each name is an h3 with a link, so screen-reader users can move person by person with the heading key.

KeyEffect
Tab / Shift+TabMoves to each name link, then to the row's action link if there is one.
EnterOpens the person, or follows the action.

Focus: the shared 2px --color-focus-ring, offset 3px, around the name link.

Labelling: portraits and initials tiles are decorative (alt="", aria-hidden="true") because the name is written beside them. Action links name the person: Message Leah, never just "Message".

Motion: the portrait's 103% scale runs only under prefers-reduced-motion: no-preference.

Touch: the name link is at least 24px tall; keep the action link on its own line so it does not crowd the name.

Content

  • Names are full names as people write them: Hannah Kowalski.
  • Meta is role · team or place, under 40 characters: "Researcher · Harbour Notes".
  • A status pill states availability in plain words, with a time when it ends: "Focused until 2 pm".
  • In a stacked list, start the meta with the person's relation to the thing: "Hosting", "Going".

Do and don’t

The person list reads the border, muted and accent-subtle roles, the h4 type role, --radius-md, the --space-12 and --space-16 portrait sizes and --layout-gutter between columns.
