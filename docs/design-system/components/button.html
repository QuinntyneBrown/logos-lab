Button

Trigger one action. A sage pill marks the one thing that matters; everything else stays quiet.

Overview

Use a button to do something: save, send, invite, confirm. Use a link to go somewhere. Keep one primary button in each group of actions — the sage pill is the single thing a person should notice first. Secondary actions are quiet outlined pills; the least important actions are text buttons.

Kit component; mocks have not been written yet.

Anatomy

  1. Leading iconoptional, decorative (aria-hidden="true"), 20px line icon.
  2. Labela verb and an object in sentence case: Save changes, Invite Grace.
  3. Containera fully rounded pill, 44px tall at the default size, with the shared 2px focus ring offset 3px.

States

Hover darkens the fill (primary) or adds a linen wash (others); active presses 2px down; focus shows the sage ring. A busy button keeps its label and width, adds a spinner and sets aria-busy="true". Disabled buttons use the linen surface and the disabled text role. Toggle buttons announce aria-pressed.

Responsive behaviour

Buttons keep their label on every width and wrap inside a .form-actions or .cluster row instead of shrinking. Below 40rem, the primary action of a form or sheet may become btn--block. Icon-only buttons keep a 44px target at every width.

Theming

Every colour reads a semantic role. In dark mode the primary pill turns light sage with near-black text; focus rings follow --color-focus-ring. Component knobs --ll-button-bg and --ll-button-fg let a product tint a button without new classes.

Accessibility

Role: a native <button type="button"> (or type="submit" inside a form). A link styled as a button stays an <a href>.

KeyEffect
Tab / Shift+TabMoves focus to and from the button.
Enter, SpaceActivates it. Links styled as buttons activate with Enter only.

Focus: the 2px --color-focus-ring outline, offset 3px, is always visible on keyboard focus.

Labelling: icon-only buttons need aria-label; a busy button keeps its accessible name and sets aria-busy. Toggle buttons use aria-pressed, never a changing label.

Motion: colour transitions take 240–420ms; the 1px lift and arrow nudge disappear under reduced motion.

Touch: 44px tall by default; never smaller than the 24px minimum target.

Content

Start with a verb, name the object, use sentence case: Save changes, Invite Grace, Delete project. Avoid "OK", "Submit" and "Click here". Keep labels to three words where you can; never end with punctuation.

Code

Use .btn with one modifier. Add .btn--sm or .btn--lg for size, .btn--block for full width, and put a .spinner first while busy.

<button class="btn btn--primary" type="button">Save changes</button>
