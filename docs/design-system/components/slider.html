Slider

Set an approximate value along a range — focus hours, text size, distance — with the current value always in words beside it.

Standard componentContrast verifiedUnused in mocks

Overview

Use a slider when an approximate value is fine and seeing it change helps: how many hours to protect for focus, how large the text is, how far to search. When people know the exact number they want, use a number text field — or pair the two, as in the with number variant. Do not use a slider for a handful of named choices; use a radio group or select. The control is the native input type="range" tinted with the accent.

Not used in the mocks yet.

Anatomy

  1. Label row.range__label: the label on the left and the current value on the right.
  2. Valueoutput.range__value, the value with its unit, updated as the thumb moves.
  3. Track and thumb.range__input, the native range in the accent colour, with a 44px tall target.
  4. Endsoptional .range__ends, the minimum and maximum in caption text (hidden from assistive technology).

Sizes

One size. The native track fills its column and the input keeps a 44px tall target.

States

Focus draws the sage ring around the slider's target area. Disabled greys the track and thumb, and the label and value. Hovering and dragging use the browser's native thumb feedback; the value in the label row updates while dragging. A slider is never invalid — it cannot hold an out-of-range value — so validate the paired number field instead.

Responsive behaviour

The slider fills its column at every width, and the value stays at the end of the label row. With a paired number field, the slider shrinks and the number field keeps its 5rem width; below 360px, keep the unit addon to a short abbreviation (km, px).

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: native <input type="range"> (slider). Set aria-valuetext to the value with its unit, and update it with the visible value.

KeyEffect
Tab / Shift+TabMoves to and from the slider.
Right / UpIncreases the value by one step.
Left / DownDecreases the value by one step.
Page Up / Page DownChanges the value by a larger step (about a tenth of the range).
Home / EndJumps to the minimum or maximum.

Focus: the 2px ring sits around the slider; the thumb keeps the accent colour.

Labelling: a visible label linked with for; the output uses for to point back at the slider. The ends are aria-hidden, because the minimum and maximum are already announced. A paired number field has its own label, visually hidden when the slider's label already shows on screen.

Motion: the thumb follows the pointer with no easing; nothing animates on its own.

Touch: dragging must never be the only way to set a value (WCAG 2.5.7): the keyboard always works, and precise values get a paired number field.

Content

  • Label what is being set: Weekly focus time, Group size for Field Day.
  • Always show the value with its unit, in words people would say: 12 hours, 6 people, 15 km.
  • Ends use the same unit as the value, or plain words when the scale has no unit (Smaller, Larger).

Code

Wrap the label row, input.range__input and optional .range__ends in .range, inside a .field. Put the value in output.range__value and update it, with aria-valuetext, on input.

<div class="field"><div class="range"><div class="range__label"><label for="s705-sl-focus">Weekly focus time</label><output class="range__value" for="s705-sl-focus" data-format="{value} hours">12 hours</output></div><input class="range__input" id="s705-sl-focus" name="s705-focus" type="range" min="0" max="20" value="12" aria-valuetext="12 hours"></div></div>
