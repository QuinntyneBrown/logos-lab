Combobox

Search suggestions under the site search field, grouped into Courses, Experts and Topics, with the typed text highlighted and a last row to see all results.

Overview

The combobox turns the site search field into a quick jump: after two characters it suggests matching courses, experts and topics, and Enter on the field goes to the full /search page. Use it only for site search in the top bar and on the search page. For choosing a value in a form use a select; for a list of actions use a menu.

Not used in the mocks yet.

Anatomy

  1. Comboboxdiv.combobox, a positioning wrapper around the field and the list.
  2. Fieldthe site search field, with role="combobox", aria-expanded and aria-controls.
  3. Listul.combobox__list, a raised listbox absolutely positioned 8px below the field, up to --size-combobox-max tall, scrolling. The specimens on this page add style="position: static" only so the list shows in flow.
  4. Group__group, an overline naming the group: Courses, Experts, Topics.
  5. Option__option, an icon, the text (__text) with the typed characters in mark, and a meta (__meta).
  6. Status__status, one line for searching, too short, no matches or failed; __status--danger for failure.
  7. Foot__foot, the last option, See all results for the query.

Sizes

the list matches the field's width and caps at --size-combobox-max.

States

Hover washes an option in --color-bg-subtle. Selected (the active option, reached by arrow keys) fills it with the sage wash and sets aria-selected="true". Searching shows a spinner and "Searching…". Too short asks for at least 2 characters. No matches says so and still offers the full search. Failed says suggestions are unavailable; Enter still runs the full search.

Responsive behaviour

The list is as wide as the field at every size. Under 640px the top-bar search opens as a full-width sheet and the list fills the space below the field; long option text truncates with an ellipsis and the meta stays. From 1024px the list hangs under the field in the top bar.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: the field is a combobox (aria-autocomplete="list", aria-expanded, aria-controls) that owns a listbox. The active option is announced through aria-activedescendant; group labels are presentation and their names are repeated in each option's meta. A separate polite live region announces the count ("3 suggestions") and each status line.

KeyEffect
Down / Up arrowMoves the active option; opens the list if closed.
EnterOpens the active option, or runs the full search when none is active.
EscapeCloses the list; a second Escape clears the field.
Home / EndMoves the caret in the field, not the list.

Focus: focus stays in the field the whole time; only the active option changes.

Labelling: the field has a visually hidden label, "Search Logos Lab". Highlighting uses mark and weight, never colour alone.

Motion: none; the list appears and updates instantly.

Touch: options are 44px tall; tapping one opens it.
