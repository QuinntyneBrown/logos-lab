Empty state

Turn an empty list into a next step. A sage icon tile, a plain title, one helpful sentence and the action that fills the space.

Core componentContrast verified

Overview

Show an empty state wherever a list, table or panel has nothing to show: before anything is created, when a search or filter matches nothing, when the person cannot see the content, or when it failed to load. It sits in the exact space the content would take, inside a dashed outline. It always explains why it is empty and offers the next step. For a whole screen that failed, use an error page; for a problem with something that is still on screen, use an alert.

Not used in the mocks yet.

Anatomy

  1. Icon tilea 56px rounded square in the accent tint with a 28px line icon; danger tint for errors.
  2. Titlea heading that states the situation, in --text-h3.
  3. Textone or two sentences, up to 44 characters wide, in muted text.
  4. Actionsone primary action that fixes the emptiness, plus at most one quiet alternative.
  5. Outlinea dashed hairline in --color-border-strong with large corners.

Empty state · compact

Sizes

an empty state fills the space of the content it replaces. Use the default for a page-level list and empty--compact inside cards, asides and tab panels.

States

An empty state is itself a state of the list or panel, so it has no states of its own. Its actions follow the button states. When the person acts (writes the first note, clears filters), replace the empty state with the content in the same place.

Responsive behaviour

At 360px the padding shrinks with the container, the text wraps to the narrow measure and the actions wrap, centred, one per line if needed. From 768px actions sit side by side. The outline always matches the content area; it never spans wider than the list it stands in for.

Theming

The icon tile reads the accent-subtle pair (or the danger pair for errors), the text reads muted, and the dashed outline reads --color-border-strong; each has a dark value, so dark mode needs no extra rules.

Accessibility

Role: a group of ordinary content: a heading at the right level for the page (usually h2 or h3), a paragraph and buttons or links. When it replaces results after a search, announce the change in a role="status" message ("No notes match venue budget").

KeyEffect
Tab / Shift+TabMoves to the actions in order.
Enter, SpaceActivates an action.

Focus: do not move focus into the empty state. After "Clear filters", keep focus on a sensible control, such as the search field.

Labelling: the icon is decorative (aria-hidden="true"); the title says what is going on. Actions name the result: "Write the first note", "Ask Caleb for access".

Motion: none.

Touch: actions are full-size buttons, 44px tall (36px in the compact form).

Content

The title states the situation plainly, without blame or jokes: No notes match “venue budget”, These notes are private, We couldn't load the tasks. The sentence says why and what happens next. The action starts with a verb and names the result. Say "we" for our failures and never "you" for the person's mistakes. Use real names: Caleb Morgan can add you.

Code

Use .empty with an .empty__icon tile, a heading with .empty__title, one <p> and .empty__actions. Add .empty--error for load failures and .empty--compact inside small containers.
