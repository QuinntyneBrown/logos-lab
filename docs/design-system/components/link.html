Link

Go somewhere — an underlined sage word in a sentence, or a standalone link with an arrow that leads on.

Overview

Use a link to go somewhere: another page, a section, a file, another site. Use a button to do something — save, send, delete — even when it should look light (.btn--text). Links inside running text stay underlined so they never depend on colour alone. Standalone links (.link-standalone) sit on their own line at the end of a card or section, set in the label face with an optional icon.

Used in 2 mock states.

Anatomy

  1. Textsays where the link goes, in sentence case.
  2. Underlinea 1px line offset from the text; it thickens to 2px on hover.
  3. Iconoptional 16px arrow (leading on), chevron (back) or external glyph, decorative.

Sizes

Links take the size of the text around them. Standalone links use the label style (15px, medium weight).

States

Hover shifts the colour to the deeper link role and thickens the underline; a standalone arrow nudges forward. Focus draws the 2px sage ring offset 3px. Danger links keep their danger colour on hover. Links are never disabled: if a destination is not available, remove the link and show plain text explaining why.

Responsive behaviour

Inline links wrap with their sentence. Standalone links keep their icon with the last word and wrap underneath on narrow screens. On phones, give a standalone link its own line so its target is at least 24px tall and does not crowd neighbouring links.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Read the Harbour Notes sharing guide before you invite guests.

Accessibility

Role: native <a href> (link). An anchor without href is not a link; never use one as a button.

KeyEffect
Tab / Shift+TabMoves to and from the link.
EnterFollows the link. Space scrolls the page, as for every link.

Focus: the shared 2px sage ring, offset 3px, with a small radius, always visible on keyboard focus.

Labelling: the link text alone must say where it goes, because screen reader users browse lists of links: See all notes in Harbour Notes, not "Click here". Repeated links (one per card) add context with visually hidden text. Links that open a new tab say "(opens in a new tab)".

Motion: colour changes take 160ms; the arrow nudge is removed under reduced motion.

Touch: keep at least 24px between stacked standalone links, or give each one its own line.

Content

  • Say where it goes, front-loaded: Back to projects, Field Day park map, See all notes in Harbour Notes.
  • Never "Click here", "Learn more" or "Read more" on their own.
  • Name files with their type and size: Download the agenda (PDF, 240 KB).
  • Keep an inline link to the few words that describe the destination, not the whole sentence.

Do and don’t

Tokens

Links read --color-fg-link and --color-fg-link-hover, the danger foreground for .link-danger, the hairline and thick border widths for the underline, and the underline offset.

TokenLightDark
--color-fg-link
--border-width-hairline
--link-underline-offset
--color-fg-link-hover
--border-width-thick
--color-danger-fg
--space-2
--text-label
--space-4
--duration-fast
--ease-standard
--duration-base
--lift-nudge

Code

A plain <a href> needs no class. Add .link-standalone for a link on its own line, .link__arrow on its trailing arrow icon, and .link-danger for a link to a destructive flow.

<p>Read the <a href="#">Harbour Notes sharing guide</a> before you invite guests.</p>
