Search and filter toolbar

Say how many results there are, let people sort them, and keep every filter in view and easy to undo.

Overview

The toolbar sits between a page's search and its results. It states the result count, offers a sort select and, below 1024px, a Filters button that opens the filter sheet. When filters are on, a stacked toolbar lists them as removable pills so nothing narrows the results silently. The filters panel groups checkboxes, chips and a slider into labelled fieldsets: a sticky sidebar from 1024px, a bottom sheet (popover) below it. For a table's own sort and paging use table and pagination.

Kit component; mocks have not been written yet.

Anatomy

  1. Count.toolbar__count: "Showing 1–12 of 86 notes", with the numbers in the default colour.
  2. Tools.toolbar__tools: the Filters button (.filters-btn, hidden from 1024px) and a labelled sort select.
  3. Active filters.active-filters: removable pills for each applied filter, plus Clear all.
  4. Filters panel.filters: a head (.filters__head) with title and Clear all, then one .filter fieldset per facet.
  5. Facetfieldset.filter with an overline .filter__legend and its controls: a .filter__list of checks with counts, a row of chips, or a range.
  6. Done.filters__done: a full-width primary button that closes the sheet and states the new count.

Sizes

one size. Tools use the small button and the default select so the toolbar stays one line high on wide screens; facets inherit their controls' sizes.

States

The sort select and Filters button follow their own states: hover darkens the border, focus draws the sage ring. Empty replaces the count with what matched nothing and offers to clear filters; the toolbar never disappears, so people can always undo. Checked facets, pressed chips and the range value are reflected in the active-filter pills.

Responsive behaviour

  • 360px: the count takes its own line and the tools wrap beneath it; the Filters button opens the panel as a bottom sheet (up to 86% of the viewport, scrolling inside) with a full-width Show 14 notes button. Active-filter pills wrap onto as many lines as they need.
  • 768px: count and tools share one line; the sheet still opens from the bottom.
  • 1024px and up: the panel becomes a sticky sidebar beside the results, the Filters button and the Done button hide, and changes apply as they are made.

Theming

The toolbar draws only a hairline (--color-border-default) under itself; the sheet uses --color-bg-surface-raised with --shadow-4 and the shared backdrop. Pressed chips and active pills read --color-accent-subtle with --color-fg-accent in both themes.

Accessibility

Role: the count is a paragraph with aria-live="polite" so a new count is announced after each change. The panel is an <aside> labelled by its title; each facet is a <fieldset> with a <legend>; active filters are a labelled <ul>.

KeyEffect
Tab / Shift+TabMoves through the Filters button, the sort select, each pill's remove button and Clear all.
Enter, SpaceOpens the sheet, toggles a chip or checkbox, or removes a filter.
Arrow keysChange the sort option or the range value.
EscapeCloses the filter sheet and returns focus to the Filters button.

Focus: the shared sage ring on every control. When a pill is removed, focus moves to the next pill, or to the count when none are left.

Labelling: the sort select is wrapped in its visible label "Sort by". Each remove button says what it removes ("Remove filter Author: Grace Liu"). The range has aria-valuetext in words.

Motion: the sheet settles in over 360ms; under reduced motion it appears without movement.

Touch: checks and chips are at least 36px tall; pill remove buttons keep the 24px minimum and sit at the pill's end, away from the next pill.

Content

  • Count with the noun: "Showing 1–12 of 86 notes", "14 notes match". Never "Results: 14".
  • Empty states say what matched nothing and how to widen it: "No notes match “launch plan” in Decisions".
  • Pills read Facet: value ("Author: Grace Liu"), or a short phrase for ranges ("Edited in the last 30 days").
  • The Done button states the outcome: Show 14 notes, not "Apply".
