Table

Compare the same few facts across many rows: a captioned, hairline table that sorts, selects and scrolls without losing its header.

Overview

Use a table when people compare the same attributes across rows — members and their roles, a budget, an activity log — and may sort or act on several rows at once. Keep it to the columns that drive a decision; put the rest on the row's detail page. Use a list when each item is read on its own, and cards when items are visual or have uneven content.

Kit component; mocks have not been written yet.

Anatomy

  1. Framea rounded hairline container that scrolls sideways when the table is wider than the page (.table-wrap).
  2. Captionthe table's name, in the label style, above the header.
  3. Header row<th scope="col"> cells on the sunken surface in muted label text; sortable headers hold a button.
  4. Rowsbody-small text separated by hairlines; numbers align right (.num).
  5. Bulk baroptional sage band above the table that counts the selection and offers bulk actions (.bulk-bar).

Sizes

Two row heights: the default (--space-3 vertical padding) for most tables and data-table--dense (--space-2) for logs and long lists. Type stays at body-small in both.

States

Hover washes the row in --color-bg-subtle. Selected rows turn sage; in a selectable table the checkbox is the source of truth and the bulk bar counts the rows. Loading keeps the caption and header and fills the body with skeleton lines of the expected shape. Empty replaces the body with a short message and the action that fills it. Error says the rows did not load and offers a retry, without losing the header.

Responsive behaviour

At 360px the frame scrolls sideways while the page stays put; keep the identifying column first so it is always in view, and drop optional columns before the table needs to scroll. From 768px most member and budget tables fit without scrolling. Below 768px, a table of fewer than four columns that people read row by row may become a list instead. The bulk bar wraps its actions under the count.

Theming

The frame and rows sit on --color-bg-surface, the header on --color-bg-surface-sunken, and hairlines use --color-border-default. Hover and selection read the subtle and accent-subtle roles, which keep body text above 4.5:1 in both themes.

Accessibility

Role: a native <table> with a <caption> and <th scope="col"> headers; it follows the APG table pattern. Don't use role="grid" unless every cell is navigable with the arrow keys (the APG grid pattern).

KeyEffect
Tab / Shift+TabMoves through sort buttons, checkboxes and row actions in reading order.
Enter, SpaceActivates a sort button; Space toggles a row's checkbox.
Arrow keysScroll a focused, scrollable frame sideways or down.

Focus: every sort button, checkbox and action shows the sage ring. A scrolling frame is a labelled region with tabindex="0" so keyboard users can reach and scroll it.

Labelling: the caption names the table. aria-sort on the sorted header announces the order; the sort button's text is the column name. Row checkboxes are labelled with the row's name (Select Daniel Reyes), row actions too (More actions for Harbour Notes). The action column's header is visually hidden but present. A loading table sets aria-busy; an error row is an alert.

Motion: row hover is an instant colour change; skeletons shimmer slowly and stop under reduced motion.

Touch: checkboxes sit in a 48px column; row actions are btn--sm and icon-btn--sm targets with --space-2 between them.

Content

Caption every table with what it lists: Northwind members, Field Day budget. Headers are one or two words in sentence case. Write dates the same way in every row (Today, 9:12 am, 2 Oct 2026), put units in the header or on every value, and replace blanks with words (Not yet). Empty and error rows say what happened and what to do next.

Do and don’t

Code

Wrap every table in .table-wrap. Add data-table--dense or data-table--sticky as needed, and table-wrap--scroll (with the --ll-table-max-height knob) to limit the frame's height.

  <caption>Northwind members</caption>
  <thead><tr><th scope="col">Name</th><th scope="col">Role</th><th scope="col">Status</th><th scope="col" class="num">Notes</th><th scope="col">Last active</th></tr></thead>
  <tbody>
    <tr><td>Amara Osei</td><td>Product designer</td><td><span class="badge badge--success">Active</span></td><td class="num">42</td><td>Today, 9:12 am</td></tr>
