Timeline

Tell what happened, or what will happen, in order. A hairline spine with small sage rings, a time and one sentence each.

Overview

Use a timeline for a short sequence where order and time matter: a project's history, the agenda for a gathering, the milestones of a release. Each entry is one moment with a time and one sentence. For a feed people act on, use notification items; for steps someone completes, use a stepper; for many dated records, use a table.

Kit component; mocks have not been written yet.

Anatomy

  1. Spinea hairline down the left edge in --color-border-default.
  2. Markera small ring in --color-accent on the canvas colour; the current entry fills it.
  3. Timea <time datetime> in the subtle caption style.
  4. Entryone sentence, optionally with a bold title and a muted detail line.

Sizes

one size. Entries grow with their text; the marker and spine stay the same.

States

A timeline is passive. The current entry — the session happening now in an agenda, or the step a project is on — fills its marker with sage and adds a soft halo, and carries aria-current ("time" in an agenda, "step" in milestones) so the meaning is not in colour alone. Links inside follow the link states.

Responsive behaviour

The timeline is one column at every width; the spine stays on the left and entries wrap. At 360px times sit above the sentence (as always), so nothing needs to change. From 1024px keep the column under 44ch for activity and agenda; do not stretch it across a wide page.

Theming

The spine, marker and text read semantic roles. In dark mode the ring turns light sage and its centre takes the dark canvas, so the marker reads as a ring on both themes.

Accessibility

Role: an ordered list (<ol class="timeline">), because order is the meaning. Give it an aria-label when there is no visible heading. Each entry starts with a <time datetime> so assistive tech and translation tools get the exact moment.

Focus: the list is not a focus stop; links inside are.

Labelling: the current entry uses aria-current="time" or aria-current="step". Write each entry so it makes sense on its own: "Grace Liu moved Onboarding checklist to Review", not "Moved it".

Motion: none. New entries appear without animation.

Touch: links inside keep the 24px minimum target; give the whole sentence enough line height to tap.

Content

One sentence per entry, in the past tense for history and as a plain noun phrase for an agenda. Name the person first and the thing second: Daniel Reyes added 3 notes to Harbour Notes. Use relative days for the last two days (Today, 9:12 am, Yesterday, 4:40 pm), then the short date (Wed 7 Oct). Times use am and pm in lowercase.

The timeline reads --color-border-default for the spine, --color-accent and --color-bg-canvas for markers, --color-fg-subtle for times, and the spacing scale for the indent and gaps.

Code

Use <ol class="timeline"> with one <li> per entry, each starting with <time datetime>. Add aria-current="time" or aria-current="step" to the current entry.

<ol class="timeline" aria-label="Northwind activity"><li><time datetime="2026-10-09T09:12">Today, 9:12 am</time><p>Grace Liu moved <a href="#">Onboarding checklist</a> to Review.</p></li><li><time datetime="2026-10-08T16:40">Yesterday, 4:40 pm</time><p>Daniel Reyes added 3 notes to <a href="#">Harbour Notes</a>.</p></li><li><time datetime="2026-10-07T11:05">Wed 7 Oct, 11:05 am</time><p>Amara Osei invited Noah Fischer to Northwind.</p></li><li><time datetime="2026-10-05T08:30">Mon 5 Oct, 8:30 am</time><p>Caleb Morgan created Northwind.</p></li></ol>
