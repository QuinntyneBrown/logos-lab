Notification item

A list of updates people can come back to: unread rows wear a sage wash and a dot, read rows fall quiet.

Overview

Use a notification list on a notifications page or in a popover from the top bar's bell, for updates people may want to revisit: a comment, a reminder, an invitation. Each row says who did what, gives one line of context and the time. Unread rows have a sage wash and a dot; reading them clears both. For a message that needs attention right now and then goes away, use a toast; for a conversation, use an inbox.

Not used in the mocks yet.

Anatomy

  1. Dot.unread-dot (8px sage) on unread rows; .read-dot, an empty spacer of the same size, on read rows so the text never shifts.
  2. Title.notice__title, one line in the h4 role that links to the thing: "Grace Liu commented on the Northwind brief".
  3. Text.notice__text, one muted line of context or a short quote.
  4. Actions.notice__actions, optional: at most two small buttons for an invitation or a request.
  5. Time.notice__time, a caption with a <time datetime>: "9:42 am", "Yesterday, 4:20 pm", "Thu 8 Oct".
  6. Rowli, a hairline under each; unread rows (.is-unread) get --color-accent-subtle and rounded corners.

Sizes

one content-driven size. Rows grow with their text; the dot and time columns keep their widths.

States

Unread rows have the sage wash, the sage dot and a hidden "Unread:" prefix. Hover washes a read row in --color-bg-subtle (an unread row deepens to --color-accent-subtle-hover) to show the whole row leads somewhere. Opening the item, or Mark all as read, removes the wash. After answering an action, replace the buttons with an inline message such as "Accepted".

Responsive behaviour

  • 360px: two columns: dot and content. The time drops under the text in the content column so titles keep the full width. Action buttons wrap.
  • 640px and up: three columns, with the time right-aligned on the title's line and never wrapping.
  • 1024px and up: the list sits within the reading measure of its page or a 400px popover; nothing else changes.

Theming

Unread rows read --color-accent-subtle (sage 50 in light, sage 950 in dark), and the dot reads --color-accent. Read rows sit on the canvas with only the hairline. All text roles keep at least 4.5:1 on both backgrounds.

Accessibility

Role: a <ul> with an aria-label that names the group ("Today", "Earlier"). Each title is a link to the thing it describes; times are <time datetime>.

KeyEffect
Tab / Shift+TabMoves to each title link, then to that row's action buttons.
EnterOpens the item (and marks it read). Enter or Space answers an action.

Focus: the shared sage ring around the title link or the focused button. Answering an action moves focus to the inline confirmation that replaces it.

Labelling: the dot is aria-hidden="true"; unread rows add a visually hidden "Unread:" before the title, so the state never relies on colour. Action buttons are specific: Accept invitation, Say yes.

Motion: the row's background changes over 240ms; under reduced motion it changes instantly.

Touch: title links span the text column; sm buttons are 36px tall with an 8px gap.

Content

  • Title: who did what to which thing, in the past tense: "Daniel Reyes shipped the sync fix".
  • Text: one line of context or a short quote in curly quotation marks; no repetition of the title.
  • Time: today as a clock time ("9:42 am"), yesterday as "Yesterday, 4:20 pm", older as "Thu 8 Oct".
  • Group by "Today" and "Earlier" rather than showing a date on every row.

Code

Link tokens/tokens.css and assets/components.css, then use this markup. The data-state attribute only forces a state for review; production code uses real interaction and native attributes.

<ul class="notice-list" aria-label="Today">
  <li class="is-unread">
    <span class="unread-dot" aria-hidden="true"></span>
    <div>
      <p class="notice__title"><span class="vh">Unread: </span><a href="#">Grace Liu commented on the Northwind brief</a></p>
      <p class="notice__text">“Can we move the launch note above the timeline?”</p>
    </div>
    <time class="notice__time" datetime="2026-10-09T09:42">9:42 am</time>
