Certificate

The certificate of completion a learner earns for a course: their name, the course, the date, the author's signature and a code anyone can verify. A revoked certificate is stamped and greyed.

Overview

Logos Lab issues a certificate when a learner completes a course. The certificate page shows it, prints it and offers it as a PDF; the public verification page shows the same certificate to anyone who has the code. Use it only for a completed course; for progress use the progress bar and for a short completion fact on a card use a badge.

Not used in the mocks yet.

Anatomy

  1. Certificatearticle.certificate, a centred birch sheet with a double hairline frame (border and inset outline) and a soft shadow.
  2. Title__title, "Certificate of completion".
  3. Name__name, the learner's name as on their profile, large and light.
  4. For__for, the joining words "has completed".
  5. Course__course, the course title.
  6. Factsdl.certificate__facts, completion date, author and length.
  7. Signature__sign with __signature, the author's name set as a signature over their full name and role.
  8. Code__code, the verification address and code.
  9. Stamp__stamp, only on a revoked certificate.

Responsive behaviour

The sheet narrows with the page; under 640px the padding drops from 64px to 48px and the facts wrap onto two lines. Long names and codes wrap rather than overflow. Print uses the same layout on a white page.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: an article named by its title. Facts are a description list. The stamp is plain text, so "Revoked" is read first.

Focus: the certificate itself takes no focus; its actions (Download PDF, Copy link) sit outside it.

Labelling: the code is printed as text and the verification address is spelled out so it can be typed. The signature is decorative type over the author's printed name, which carries the meaning.

Motion: none.

Touch: none on the certificate; actions outside it follow the button rules.

Content

The learner's name is exactly as on their profile: Miriam Clarke. Dates are 2 Sep 2026. The code is uppercase in two groups of four: LL-7K4Q-29XM. The joining words are has completed. The revocation alert gives the date and what it means, not the reason, which goes to the learner privately.
