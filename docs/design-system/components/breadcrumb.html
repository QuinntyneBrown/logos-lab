Breadcrumb

A short trail from the current page back up through its parents. Small text, quiet slashes, and the current page unlinked at the end.

Core componentContrast verified

Overview

Use a breadcrumb on pages that sit two or more levels deep, so people can see where they are and step back up: a checklist inside a project, a note inside a notebook. It goes above the page title in the page header. Leave it off top-level pages and flows; the top bar already covers those, and a stepper shows progress through a flow. A breadcrumb shows hierarchy, not history: never fill it from the back button.

Kit component; mocks have not been written yet.

Anatomy

  1. Landmark<nav aria-label="Breadcrumb"> around an ordered list.
  2. Ancestor linkeach parent level as a link, in the body-small type style.
  3. Separatora slash in the subtle text role, drawn by CSS so screen readers skip it.
  4. Current pagethe last item, unlinked, in the default text role with aria-current="page".

Sizes

one size. The trail uses --text-body-sm with --space-2 between items and separators; links keep the underline as their affordance.

States

Ancestor links rest in the link role with an underline; hover moves them to the link-hover role; keyboard focus draws the sage ring. The current page is plain text in the default role and has no hover or focus. The fold button in a collapsed trail follows the text button and sets aria-expanded="true" once opened. The matrix forces each state on the first link.

Responsive behaviour

  • 360px: show the back link to the parent, or the collapsed trail when the hierarchy matters; long labels wrap.
  • 768px: the full trail, collapsing past four levels.
  • 1024px and up: the full trail; it shares the page header's measure and never stretches the page.

Theming

Every colour reads a semantic role: links read the link roles, the separator the subtle text role. In dark mode the links turn light sage and the current page stays the default text role.

Accessibility

Role: a <nav> landmark named "Breadcrumb", containing an <ol> so the number of levels is announced. The current page carries aria-current="page". Separators are CSS generated content, so they are not read.

KeyEffect
Tab / Shift+TabMoves between the ancestor links (and the fold button).
EnterFollows the focused link; on the fold button, expands the trail and moves focus to the first revealed link.

Focus: the shared 2px --color-focus-ring, offset 3px, on each link.

Labelling: use one "Breadcrumb" landmark per page. Name an icon-only home link ("Home") and the fold button ("Show 2 more levels").

Motion: none; nothing to reduce.

Touch: links in the trail are small text links; on touch screens prefer the back link, whose row is 44px tall.

Content

Use each page's own title, exactly as its page header writes it: Northwind, Launch checklist. Don't add the current section from the top bar unless it is a real parent page. Never end with a separator, never link the current page, and never add "You are here".

Do and don’t

Tokens

The trail reads the link, default, muted and subtle text roles, --text-body-sm and --space-2.

TokenLightDark
--space-2
--text-body-sm
--color-fg-muted
--color-fg-subtle
--color-fg-default

Code

Use nav[aria-label="Breadcrumb"] > ol.breadcrumb > li, with a link in every item but the last and aria-current="page" on the last.

<nav aria-label="Breadcrumb"><ol class="breadcrumb"><li><a href="#">Projects</a></li><li><a href="#">Northwind</a></li><li><span aria-current="page">Launch checklist</span></li></ol></nav>
