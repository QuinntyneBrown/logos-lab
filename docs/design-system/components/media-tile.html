Media tile

A captioned 4:3 tile for a screenshot or photo, or a calm illustrated placeholder when there is no image yet. Tiles sit in a two- or three-column grid.

Overview

Use media tiles to show a few images of a piece of work: screenshots of Northwind, photos from Field Day, pages from Harbour Notes. Each tile has a short caption beneath. When there is no image yet, the illustrated placeholder (soft bars on a tile tone) keeps the grid's rhythm without pretending to be content. For one large image use the hero's photo frame, and for a person's picture use an avatar.

Kit component; mocks have not been written yet.

Anatomy

  1. Grid.shots: two columns, three from 768px, with a 16px gap.
  2. Figureone figure.shot per image.
  3. Tilethe 4:3 frame (__tile) with soft corners and a hairline; a link when it opens a larger view.
  4. Image or placeholderan <img> that covers the tile, or __bars on a tile--* tone.
  5. Captiona figcaption in the caption style, one short line.

Tones

The four tile tones. Pick one per project and keep it, so its placeholders read as one set.

Media tile · tones

Sizes

One shape. Tiles are always 4:3 and take the width of their grid column, so a row of mixed images stays even.

States

Hover on a linked tile darkens the hairline, lifts a soft shadow and eases the image in by 3%; focus draws the sage ring around the tile. Loading fills the tile with the subtle background and a slow shimmer until the image arrives. Error keeps the tile's place with a dashed outline, an icon and a plain "Image didn't load" so the caption still makes sense.

Responsive behaviour

Two columns at 360px, three from 768px; tiles keep 4:3 at every width. Captions wrap onto a second line rather than being cut off. At 1024px and up the grid sits inside the page column and never grows past three tiles per row; show more images in a viewer, not in a wider grid.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: each tile is a <figure> with a <figcaption>. A tile that opens a larger view is a link (a.shot__tile); a placeholder is role="img" with an aria-label.

KeyEffect
Tab / Shift+TabMoves between linked tiles.
EnterOpens the larger view.

Focus: linked tiles show the 2px --color-focus-ring outline around the frame.

Labelling: images have alt that says what is shown, not "screenshot of". A linked tile's aria-label says what opening it does ("Open screenshot: The board view"). Placeholder bars are decorative; the tile itself carries the name. A failed image says so in text.

Motion: the hover zoom and the loading shimmer stop under reduced motion.

Touch: tiles are far larger than the 44px target; leave the 16px gap so neighbours are not tapped by mistake.

Content

Captions name what the image shows in a few words, in sentence case and without a full stop: The board view, Weekly summary e-mail, Field Day planning, Thursday. Avoid "Screenshot 1" or file names. Write alt text as one plain sentence about the picture.

Code

Put figure.shot items in .shots. Use a.shot__tile when the tile opens a viewer and div.shot__tile otherwise; add a tile--* tone and .shot__bars for a placeholder, or an <img> for an image.
