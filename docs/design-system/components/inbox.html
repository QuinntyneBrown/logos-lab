Inbox

The list of conversations. Each row is a link with a portrait, a name, the last line and when it was sent; unread rows carry a sage dot.

Standard componentContrast verifiedUnused in mocks

Overview

Use an inbox to list someone's conversations, newest first, beside or above the open message thread. Every row is one link to one conversation. For a feed of events that are not conversations (mentions, reminders) use a notification item list; for people you have not talked to yet use a person list.

Not used in the mocks yet.

Anatomy

  1. Containera rounded surface (.inbox) with a hairline border; rows are divided by hairlines.
  2. Rowone link per conversation (a.inbox__item), the whole row is the target.
  3. Portraita 40px avatar, decorative beside the name.
  4. Namewho the conversation is with (__name), cut off with an ellipsis when long.
  5. Snippetthe last message, one line (__snippet).
  6. Timewhen the last message arrived (__time); optionally stacked with an unread count (__end).
  7. Unread dota sage dot after the name on .is-unread rows.

Portraits, names and the last line. One conversation is open (aria-current); one is unread.

Sizes

One size. Rows are at least 64px with a portrait and 56px in the compact variant, so each one is a comfortable target.

States

Hover washes a row in linen; focus draws the sage ring inside the row so the container does not clip it. Current (the conversation that is open) keeps the sage wash. Unread adds the sage dot after the name and lifts the snippet to the default text colour. Loading shows skeleton rows in the same shape; empty says there are no conversations yet and how to start one.

Responsive behaviour

At 360px the inbox is the whole screen; opening a row shows the thread full screen with a Back link. From 768px the inbox sits beside the thread in a split view, about 22rem wide (--layout-list-pane), and the open conversation stays marked current. At 1024px and up nothing else changes; names and snippets cut off with an ellipsis rather than wrapping, so rows keep one height.

Theming

Every colour comes from a semantic role, so the dark theme needs no component-specific rules. A light specimen nested under a dark root resets its roles.

Accessibility

Role: a <nav> named "Conversations" containing one link per conversation. The open conversation has aria-current="true" (or "page" when each conversation has its own URL).

KeyEffect
Tab / Shift+TabMoves from row to row.
EnterOpens the conversation.

Focus: the 2px --color-focus-ring outline is drawn inside the row, because the rounded container clips anything outside it.

Labelling: each link's name is its text: the name, the last line and the time. Unread is not only a dot: add "(unread)" as visually hidden text after the name, and a hidden "Unread messages:" before a count. Portraits are decorative (alt=""). Prefix your own last message with "You:".

Motion: hover and current washes change colour only, with no movement.

Touch: every row is at least 56px tall and the whole row is the link.

Content

Names are full names or a group's name (Northwind team). The snippet is the last message, cut off by the layout rather than by hand; prefix it with the sender in groups (Noah: Offline mode is ready to try.) and with You: for your own. Times are short: 9:18 am today, Yesterday, a weekday this week (Mon), then a date (28 Sep).

Code

Use a nav.inbox of a.inbox__item rows: a portrait, a div with __name and __snippet, and a __time (or __end holding the time and a count). Add is-unread and aria-current="true" as needed; add inbox--compact to drop the portraits.
