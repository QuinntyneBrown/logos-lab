Skip link

The first thing a keyboard reaches. A dark pill that appears on focus and jumps past the top bar to the page's main content.

Overview

Every page starts with a skip link so keyboard and switch users can pass the top bar in one keystroke instead of tabbing through every link in it. It stays hidden until it has focus, then appears over the top-left corner of the bar. It is required on every page that has repeated navigation before the content; pages without any, such as a bare sign-in card, can leave it out.

Kit component; mocks have not been written yet.

Anatomy

  1. Linkthe first focusable element in <body>, pointing at the main landmark: href="#main".
  2. Pillinverse surface and text, fully rounded, the label type style; it sits above every layer (--z-tooltip).
  3. Target<main id="main" tabindex="-1">, so focus really moves there and the next Tab continues from the content.

Sizes

one size. The pill is 44px tall (label type with --space-3 padding) so it is easy to see and to tap on a tablet with a keyboard.

States

Hidden by default: moved above the viewport and clipped, so it never shows through a nested or scrolled header. On focus it slides to --space-4 from the top-left corner, above every other layer, and keeps the shared focus ring. Hover only matters while it is visible; the label stays in the inverse text role.

Accessibility

Role: a native link (<a href="#main">). The target is the <main> landmark with id="main" and tabindex="-1"; a role="search" region can be a second target.

KeyEffect
Tab (first press on the page)Focuses the skip link and reveals it.
EnterMoves focus to the main content; the next Tab continues from there.
Tab (again, without Enter)Hides the skip link and moves to the brand in the top bar.

Focus: the pill shows the shared 2px --color-focus-ring, offset 3px. A sticky header must not cover the target: give main a scroll-margin-top equal to --layout-topbar-height.

Labelling: say where the link goes: Skip to content, Skip to search. The text is visible whenever the link has focus, so it needs no aria-label.

Motion: the pill appears in place without animation; nothing to reduce.

Touch: the pill is 44px tall. It only appears with a keyboard; it is never the only way to reach the content.

Content

Use Skip to content on every page. Add Skip to search only where search is the main task. Never more than two. Sentence case, no "Click here", no "main" (people don't think in landmarks).
