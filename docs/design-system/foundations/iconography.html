Iconography

A restrained line set on a 24-unit grid — 1.5 stroke, round caps and joins, drawn in currentColor.

Foundation
  • Principles
  • Specimens
  • Tokens
  • Usage
  • Sources

Principles

Icons are simple line drawings on a 24×24 viewBox with stroke-width: 1.5, round caps and joins, no fill, coloured by currentColor. They render at 20px (.icon), 16px (.icon--sm) or 24px (.icon--lg). The .icon class sets all of this. Inline the SVG and give it only viewBox and paths.

  • An icon beside visible text is decorative: aria-hidden="true".
  • A standalone icon control needs an action name on the control: aria-label="Edit project".
  • One meaning per icon across the product. Plus means add, the arrow means continue, the cross means close or remove.
  • Status combines an icon or dot with words.

Tokens

This foundation sets rules rather than values; the tokens it relies on live in the other foundations.

Usage

  • Draw new icons in the same hand: geometric, open and slightly rounded, with no filled shapes except the brand's sun dot.
  • Keep icons optical: 2px of padding inside the 24-unit box, centred on the pixel grid.
  • The brand mark is the only illustration with a fill. A single warm dot (.brand__sun, the warning icon tone) sits beside a line mark. Each product draws its own mark in this style. See Brand.
  • Never use an icon font or emoji as an icon.
