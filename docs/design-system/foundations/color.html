Color

Oat, birch and one accent by day; warm charcoal by lamplight. Roles, not values, decide which colours touch.

Foundation
  • Principles
  • Specimens
  • Tokens
  • Usage
  • Sources

Principles

The palette is warm and quiet. Pages sit on oat, cards and fields on birch paper, and dialogs and menus on a slightly brighter raised surface. Linen wells (--color-bg-surface-sunken) sit below the reading plane. One accent (sage by default) marks the single most important thing on a screen: the primary action, the current tab, a selected filter. Everything else stays neutral.

  • Read colour by role. Components use --color-bg-*, --color-fg-*, --color-border-*, --color-accent* and the status families. They never use --palette-* primitives or hex values.
  • One accent moment per view. If two things are sage, neither is important.
  • Status always has words. Info is fjord blue, success is sage, warning is clay and danger is lingonberry red. Each tone appears with an icon or dot and text, never colour alone.
  • Hairlines before boxes. --color-border-default separates content quietly. Inputs and focus indicators use --color-border-strong and --color-focus-ring so that controls meet 3:1.
  • Dark is lamplight, not blue-black. Night surfaces are warm charcoal and get lighter as they rise. The accent turns pale with near-black text on it.

Tiles

Initials, project marks and illustrated tiles use the four tile roles (--color-tile-sage, -clay, -fjord, -oat) with --color-tile-fg. Choose a tile from a stable hash of the name so a person keeps their colour.

Usage

  • New colour roles are added to tokens.css in the :root block and the dark block, and every new foreground/background combination is added to tokens/contrast-pairs.json. Run check_contrast.py before using the role.
  • The accent ramp lives between accent:start and accent:end. Recolour it only with recolour_accent.py, which rebuilds the ramp, keeps every pair at AA and leaves success sage.
  • Disabled content is deliberately subdued and exempt from the contrast minimum. Never use the disabled roles for content that is merely secondary; use --color-fg-subtle.
  • Overlays use --color-bg-backdrop (a translucent ink in light mode, a deeper black in dark mode).
