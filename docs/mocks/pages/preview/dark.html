Can Software Bear the Image of God?

Dr. Abena Mensah · not yet published

Genesis says humans are made in God's image. As software begins to speak, reason and create, some ask whether it shares that likeness. This article argues it does not, and explains why that matters for how we build and use it.

What the image is not

When Genesis 1:27 (NRSV) says that God created humankind in his image, it does not hand us a list of features: speech, reason, creativity. The Hebrew word צֶלֶם (tselem) names a likeness set up to represent someone.

That matters now, because the features are exactly what new software imitates best.

“The image is not a trait we possess; it is a calling we receive.”

Three things a model cannot do

  • A model can describe compassion; it cannot be moved by it.
  • A model can produce a prayer; it cannot address God.
  • A model can be useful in our calling; it cannot receive one.
