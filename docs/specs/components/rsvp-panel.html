RSVP panel

The registration panel of the event page: a title that names the state, one status line, the places meter, the explanation, the actions and the help text, in every state the mocks draw. Requirements: rsvp-panel.md. Design system: rsvp-panel.

Sizes

One size. The panel takes the width of its column: --layout-aside-width from 64 rem and the full width of the page below it. It has no size input.

States

Loading, focus and the keyboard path. The interaction states of the controls belong to the button; the panel has no hover or active state of its own.

AC-26, AC-27

Responsive

Component CSS uses viewport media queries, so each frame is a real viewport. The panel does not change layout across breakpoints; the frames prove the 320 px wrap with the longest closed text and the registered panel's email address, the full-width controls, and the panel in a wider column.
