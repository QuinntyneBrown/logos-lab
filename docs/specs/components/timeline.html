A timeline is passive, so there is no hover or active state. The current entry fills its marker; aria-current="false" draws nothing (D-5); a one-entry list draws one marker.

Responsive

The timeline is one column at every width, so the frames show the same layout; they prove that long sentences and comments wrap beside the spine. Each frame is a real viewport. A 320 px viewport is the layout at 400 % zoom on a 1280 px window (AC-23).
