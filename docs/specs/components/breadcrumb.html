Breadcrumb

The trail from the current page back up through its parents: links for every ancestor, plain text for the page you are on. Requirements: breadcrumb.md. Design system: breadcrumb. Styles marked "required" are specimen CSS for decisions D-2, D-4, D-6 and D-8 that the design-system stylesheet does not carry yet.

Sizes
