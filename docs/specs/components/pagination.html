Responsive

Component CSS uses viewport media queries, so each frame is a real viewport. Below 40rem the numbers collapse (D-6); below 48rem every control is at least 44 px (D-7); the 640 px frame is the narrowest at which the full row fits. The collapse and the 44 px rules are drawn by the specimen style block (pagination D-6, D-7).
