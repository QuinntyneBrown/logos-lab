Responsive

The list is one scrolling row at every width. The 320 and 360 px frames show the eight result types with "Events 1" scrolled into view (the frame script stands in for the component) and, at 320 px, a long label wrapped inside its list (D-3). At 768 px nothing scrolls.

Motion: nothing animates and scrolling into view is instant, so reduced motion changes nothing AC-31. Performance: the list is --target-comfortable tall from first paint with its counts, so it adds no layout shift AC-32.
